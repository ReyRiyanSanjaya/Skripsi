3. Perhitungan Information Gain untuk setiap Decision Tree

Langkah 2: Hitung Entropy dan Information Gain untuk setiap fitur di setiap bootstrap sample
Formula Entropy:
Entropy(S) = -Σ(pi * log2(pi))

Formula Information Gain:
IG(S,A) = Entropy(S) - Σ((|Sv|/|S|) * Entropy(Sv))

4. Voting dan Prediksi Final

Langkah 3: Lakukan voting mayoritas dari prediksi semua decision trees
Test CaseTree 1Tree 2Tree 3Vote YaVote TidakPrediksi Final
Cerah, Sedang, Normal, Lemah Ya Ya Tidak 2 1 Ya
Formula Voting:
Prediksi Final = argmax(Σ votes untuk setiap class)

Dalam Excel:
=IF(COUNTIF(range_prediksi,"Ya") > COUNTIF(range_prediksi,"Tidak"), "Ya", "Tidak")
🎯 HASIL AKHIR RANDOM FOREST:
Untuk kondisi cuaca: Cerah, Suhu: Sedang, Kelembaban: Normal, Angin: Lemah
PREDIKSI: BERMAIN TENIS = YA
(Berdasarkan voting mayoritas: 2 Ya vs 1 Tidak)

5. Formula Excel untuk Implementasi

A. Bootstrap Sampling:
=INDEX(dataset, RANDBETWEEN(1, ROWS(dataset)), COLUMN())

B. Entropy Calculation:
=-(P1*LOG(P1,2)+P2*LOG(P2,2))
dimana P1 = COUNTIF(range,"Ya")/COUNT(range)

C. Information Gain:
=Entropy_Parent - SUMPRODUCT(Weight_array, Entropy_children_array)

D. Majority Voting:
=IF(COUNTIF(tree_predictions,"Ya") > COUNTIF(tree_predictions,"Tidak"), "Ya", "Tidak")
💡 Tips Implementasi di Excel:
• Gunakan fungsi RANDBETWEEN() untuk bootstrap sampling
• Buat helper columns untuk menghitung proporsi setiap class
• Gunakan COUNTIFS() untuk menghitung kondisi kombinasi
• Implementasikan decision tree dengan nested IF statements
• Simpan prediksi setiap tree dalam kolom terpisah untuk voting
